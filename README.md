# Engineering Methods (MIP)

This repository contains an academic article written for the Engineering Methods (MIP) course. The primary goal of this project was to practice formal scientific writing, learn LaTeX for academic typesetting, and explore the application of deep learning in a real-world industry context.

The article, titled **"Deep Learning in Video Streaming Services"**, provides an overview of how platforms like Netflix and Disney+ use neural networks (CNNs, RNNs), Natural Language Processing (NLP), and Video Content Analysis to generate personalized recommendations, evaluate their performance, and improve user retention.
